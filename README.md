# Student GWA Calculator

A private, installable web app that helps Philippine students understand and manage their general weighted average (GWA).

## Features

### Term GWA calculator

Enter subjects, units, and grades to calculate a weighted term GWA instantly. The calculator also shows progress, grade status, and eligible academic distinctions.

### Cumulative records

Save completed terms, revisit previous grade records, and view a cumulative GWA based on your academic history.

### Grade predictions

Explore what-if scenarios to see the grades needed to pass, meet a target GWA, or complete remaining subjects.

### Honors guidance

View graduation-honors eligibility, Dean's List and President's List indicators, and tuition-discount information based on entered grades.

### Exportable summaries

Create a shareable image summary of your current GWA result and subject performance.

### Installable offline app

Install the calculator on a phone or desktop and continue using core features when offline. Academic records remain in the browser on the device, and the app also works offline in production, since installing it caches everything it needs to run on the device the first time it's opened.
